- **ADR-114** — **REVERTED 2026-11-14 (PR #3 merge reverted, user did not like the result; panorama renders directly as before).** Panorama anti-aliasing is configurable: σ (CSS px) of a Gaussian reconstruction filter. σ > 0.5 → the frame is supersampled (≤ 2× per axis, ≤ 8.3 MP) into an MSAA target and resolved by a separable Gaussian in linear light; the terrain shader's prefilters (texture octave fade, normal sampling width, analytic shadow-edge width via `fwidth`) widen by σ/0.5. σ ≤ 0.5 = original direct render. Default σ = 1.0 (2× the original, per user; to be tuned). Source: env `PANO_AA_SIGMA` → `/config.json` (nginx entrypoint) → `?aa=` URL override. Stars/skirt moved to ShaderMaterials with explicit sRGB encode so canvas and render-target paths match. Display only — no metric changes. — User request: smoother panorama by default, tunable without rebuild. — Post-blur at native res (blurs without adding samples); prefilter-only (measured: almost no visible change, ≤ 3 % pixels even at 8×). — 2026-11-14
- **ADR-115** — Panorama relief anti-aliasing (replaces the reverted ADR-114 approach; nothing is blurred). (1) Height-field interpolation is configurable: Mitchell–Netravali cubic family over the 5 m / 20 m panorama height fields — `catmull` (default, interpolating, C1), `mitchell`, `bspline` (C2), or the original `bilinear` — used for mesh vertices, camera height and the shading-normal central differences (16 `texelFetch` taps); the shadow ray-march keeps the cheap hardware-bilinear lookups. (2) Relief prefilter width = the true pixel footprint on the ground (major axis of `dFdx/dFdy` of the surface position) × `PANO_RELIEF_AA` (default 1) instead of `distance × 0.0012`: at grazing view angles the old isotropic estimate under-filtered the procedural micro-relief and DEM normals by 10–50×, which was the sparkle along low-Sun shadow boundaries (measured high-pass RMS 1.76 → 0.73 at 1, 0.52 at 2; mean brightness unchanged). Settings via env → `/config.json` → `?interp=` / `?raa=`. Display only, no metric changes. — User: smooth the relief, keep the picture sharp, configurable. — Supersampling + Gaussian resolve (ADR-114, reverted: blurred the image); bicubic alone (measured: barely changes the sparkle, which came from the under-filtered micro-relief). — 2026-11-14
- **ADR-116** — Bug fix: `DemClient` (TS) coarse-level fallback now mirrors `lunarcore.tiles.sample_clip`: when a level lacks a tile under any of the 4 bilinear neighbours, the whole sample is taken bilinearly at the next coarser level (NaN neighbours skipped, weights renormalised).
